# Mass 僵尸尸体验收

`BBBAnimationPreviewToolset.start_mass_corpse_acceptance` 在名称包含 Validation 的完整关卡路径中运行。需要渲染 PIE 与空闲测量器。输入一至十六个正式 Mass 模板 群体数量一至五百 出生中心 间距至少一百厘米 以及唯一临时目录名。

工具只创建和回收自己保存的完整代际句柄。不改正式模板 不删除关卡原有实体。至少预热三秒并等待全部表现演员实际创建后 通过 `BBBMassValidationLibrary.DamagePopulation` 的正式本机累计伤害输入杀死本工具群体。六十秒仍未形成完整表现群体则失败。输入拒绝或数量不符立即失败。禁止将创建数量当成实际表现数量。

使用 `inspect_mass_population_benchmark(run_id)` 查询状态。完整 JSON 存在 `Saved/temp/<file_prefix>/<run_id>.json`。每隔约四分之一游戏秒回读有效实体 表现演员 活动物理 保留姿势 骨盆高度及实际帧指标。持续二十六秒后检查五至十秒仍保留尸体 活动物理不超过三十二个 并已完成回收。所有布尔结果均须实际为 true 才能宣布验收通过。帧指标顺序为帧编号 游戏线程 渲染线程 GPU 引擎间隔 毫秒项中的零值可能表示不可用。

验收关卡切换 PIE 结束或原生错误会停止回调并保留诊断。临时结果按项目清理规则核实后删除。十种外观和五十 二百 五百只压力测试应分别执行 并结合画面检查真实倒地与冻结姿势 不能仅凭工具请求成功验收。

`ragdollsCollapsed` 要求最初参与物理的各实体在五至六秒样本中的骨盆均下降至少三十厘米。受击资产可能在刚体默认设置中关闭重力 仅调用网格级重力开关不一定覆盖该设置。此检查防止把启用物理标志或站立冻结误判为真实倒地。

`allCorpsesCollapsed` 在平坦验收地面检查全部尸体的骨盆低于出生中心四十厘米 包含预算外的死亡末帧尸体。需要选择同一平面上的出生中心。动画预算注销会恢复 URO 跳帧 因此末帧采样必须关闭跳帧并同步评估当前死亡事实 不能直接冻结旧的站立缓存。
