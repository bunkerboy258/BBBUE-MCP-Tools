# 人工双臂样板的通用动画烘焙

入口 `control_rig.process_dual_arm_body_pose(recipe_path, action, write_paths, job_index=-1)`。实现为 `Scripts/BBBDualArmBodyPoseTools.py`，源文件格式 `BBBDualArmBodyPose`、schema 1。制作源保存在角色 `Source/Animation/*_BodyPose_Authoring.json.source`，不保存临时备份。

## 操作

- `capture`：只读取人工确认的第0帧六个控制器，统一第0、1帧并保存实际组件目标。写入范围必须恰好为制作 LS。未经用户确认不得调用。
- `inspect`：按公共动画层真实类默认值递归读取动画、方向结构和数组，展开 BlendSpace，生成实际序列清单。`write_paths` 指定制作 Rig；操作本身只读。
- `bake`：明确 `bake_jobs` 的一项和对应输出包。每帧源姿态输入独立生产 Rig，禁止执行静态底稿的 BasePose。以脊柱空间迁移人工目标，握持区间保持双手关系，按 `DisableLHandIK` 保留离手轨迹。骨长和缩放保持；不可达时最多35度锁骨随动，再统一收敛整段源摆臂幅度，记录实际幅度，不逐帧突然裁切位置。失败发生在提交轨道前。成功写入输出摘要，重复调用只核验摘要，不叠加修正；摘要变化拒绝继续。
- `finalize`：全部烘焙摘要一致后才应用。`write_paths` 恰好为型号 DA、公共动画层、型号握姿 Rig 与 LS。递归改公共层真实引用、编译保存回读；按原插槽链及新双手关系计算左手 IK，保留枪械挂接。同步静态握姿制作 Rig 的 BasePose、控制器偏移及零增量关键帧，并核验完整骨姿与正式 AS 一致。更新唯一制作源和指纹。

## 动作与加法

`role=action` 的装备动作只在末段收敛；换弹开端及末段收敛，中间保留动作。默认末段0.4秒，可明确指定 `exit_seconds`。此参数是制作修正窗口，不是蒙太奇淡出时间；工具保留原蒙太奇时序。

`role=additive` 明确 `base_animation`。以原局部参考帧计算差值，在新参考姿势上重新建立原始轨道，保持局部加法差值。`base_end=true` 使用动作末帧；`replace_reference=true` 明确替换参考动画。普通烘焙保留曲线、通知、同步标记、Root Motion、帧率、长度及加法配置，逐轨道回读。加法重基准仅改变明确参考关系，其余元数据保持。

## 范围与验收

仅编辑器世界，PIE期间拒绝调用。需要已批准六控制器、骨架一致的源动画和明确写入范围。手指和非目标骨轨保持，正式输出不经过运行时 Control Rig，也不改游戏代码。

2026-10-20 在隐藏 NullRHI、GamingBackground、10FPS 宿主实测：手枪65条公共动作加5项专属动作/握姿/加法，低位持枪67条公共动作加4项专属动作/握姿/加法，共141项完成保存与摘要回读。装备、换弹的双手末帧相对脊柱位置误差低于0.00004厘米，最大旋转误差约0.016度；两份型号制作 Rig 与正式握姿完整骨姿一致。实际 DA 引用和 HeavyCarry 层注册类型已独立回读。四项离线边界与契约检查通过。没有运行PIE，画面及运行验收由用户完成。
