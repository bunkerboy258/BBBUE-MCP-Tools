# 动画导入坐标修正

`editor.import_animation_fbx` 支持 `import_pitch`、`import_yaw`、`import_roll`，默认均为零，单位为度。这些值写入原生 FBX 动画导入数据；后续重新导入可复用记录的角度。原始 FBX 不修改。

操作保持原动画包、骨架和源文件路径；拒绝未保存的目标动画，沿用公共资产写入策略保护他人签出。未受控但可写的资产允许修正，不额外要求不存在的签出状态。

导入后用实际动画采样检查头、骨盆和脚的位置，并对比网格参考姿势。`retarget.inspect_retargeter` 返回两侧参考骨骼位置、当前姿势和非单位旋转偏移，用于区分源动画轴错误与重定向姿势错误。不以参数保存成功替代姿势验收。
