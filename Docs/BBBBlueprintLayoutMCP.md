# 蓝图图表排版

公开批次默认完成本批次范围的验证、保存与回读。分阶段预览或人工检查时传 `completion="review"`。下文函数级保存行为描述对应领域实现；公开调用的完成策略以批次参数为准。

`BBBBlueprintGraphToolset.optimize_blueprint_node_layout` 根据原生引脚连接进行从左到右的分层排版。参数为 `graph_path`、`horizontal_spacing`、`vertical_spacing` 与 `dry_run`。先使用 `dry_run=true` 检查重叠、反向连线及预计移动数量，再写入。

工具先向上追溯各主节点的整条参数计算链 按最终消费者集合分组 专属参数与对应主节点作为完整区域参加布局 Aim IK 与 FABRIK 等不同主节点的参数不能混排 多消费者共享链保留一份并占据独立公共区域 无主链的纯数据图继续按输入 计算 输出排列

主链按真实姿势或执行引脚高度对齐 水平间距容纳完整参数组 固定注释框仍保留原位 避让连线时禁止辅助节点侵入其它参数组 若固定框导致无法分组则报警并拒绝写入 不通过打散参数组掩盖问题

`before` 与 `after` 中的 `dependencyGroupOverlaps` 表示不同参数组边界矩形的交叠数量 即使节点本身没有重叠也可能大于零 正式应用拒绝该值非零的布局 同时继续检查节点重叠和连线穿节点 此指标不代表同组内部所有线与线交叉均已消除

工具只移动节点坐标 事务结束后回读坐标 原始连线及固定注释 失败只恢复本次坐标 公开 MCP 批次负责保存与回读 项目最外层按本地 Git 工作流程管理 不执行 Perforce 操作

2026-10-23 验证结果: 35 项布局专项测试通过 覆盖 Aim IK 与 FABRIK 的多层参数链分离 多消费者共享链独立成组 零节点重叠但参数组混排的识别及写入拒绝 原有随机分支 固定注释框和事务回读测试保持通过
