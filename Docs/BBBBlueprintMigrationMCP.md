# 演员蓝图迁移

`BBBGenericEditorToolset.migrate_actor_blueprint` 将现有演员蓝图迁移至明确的新路径与已编译父类 同步指定默认值和关卡实例 最后删除无引用旧跳转。

- 先 `dry_run=true` 核对全部引用关卡 再执行迁移。
- `defaults_json` 使用普通 JSON 值 对象引用为 `{"refPath":"完整对象路径"}` 数组可包含对象引用。
- 要求源蓝图和全部引用关卡具备写入权限 新目标不存在 PIE 停止且没有脏包。
- 只支持非分区关卡 不自动扩大引用者范围 不创建原生类兼容跳转。
- 关卡实例保留身份与变换 指定属性统一写入 蓝图改名同步更新演员标签。
- 迁移后必须重新加载关卡核验父类与实例配置 再删除被替换的原生源码类并编译。
