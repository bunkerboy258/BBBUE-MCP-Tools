# 动画全角度观察

`BBBAnimationPreviewToolset.capture_animation_views` 在唯一渲染宿主的 PIE 世界逐姿势生成 1024 方形图。每次明确一条动画、同骨架网格、至多九个采样进度和至多三十二组 `[yaw,pitch]` 观察角度。偏航零从角色正 X 方向观察，俯仰正九十是正俯视，负九十是正仰视。使用 `[[0,90],[0,-90]]` 可直接检查上下遮挡。

完整检查使用偏航零至三百一十五度、步长四十五度，分别配合俯仰负四十五、零、四十五度，加正俯视和正仰视，共二十六个方向。选择动作首尾、四分之一、中点、四分之三及关节变化峰值，不能用单方向截图或数值正常替代视觉判断。

相机以当前骨骼包围范围自动居中并保留边缘余量，三盏随观察方向布置的无阴影补光和固定曝光用于看清关节。捕获禁用间接光与反射，保留渲染状态并跨帧预热，避免关卡环境或不完整曝光状态掩盖关节。`exposure_bias` 默认为零，调用方必须查看第一张图并根据实际材质调整，避免暗部不可辨认或高光过曝。检查人体优先裸露关节的同骨架网格，再用生产网格确认服装遮挡和穿插。

图像写入 `Saved/temp/<file_prefix>`，拒绝已有目录，返回每图角度、采样秒数、相机距离和全部骨骼位置。成功和失败均销毁临时演员、相机及灯光，不修改源资产、关卡或用户视口。任务完成后仅清理本任务目录。返回成功仅表示生成了截图，必须实际查看全角度图并检查运动连续性后再报告结果。

调用返回 `pending` 与 `captureId`。用 `inspect_animation_transition_capture` 查询，直至 `completed` 或 `failed`。截图等待材质预热及每个方向的场景更新跨过真实引擎帧，避免补光和相机仍处于旧位置。采样进行时禁止重载工具或结束 PIE；世界变化明确失败并销毁本次临时对象。

同一宿主必须串行捕获。工具拒绝已有待完成截图时启动新捕获，避免不同任务的临时灯光叠加而使亮度证据失真。

修复原姿势轨道前可调用 `BBBControlRigAuthoringToolset.sample_sequence_controls`，传入唯一控制绑定序列、明确的显示帧和 `source_` 欧拉变换控制器名称。每次至多六百帧，读取实际控制器关键帧并返回组件空间变换，不写入源资产；必须在编辑器世界调用。它避免以不同网格的重定向骨骼位置代替源控制器值。

每张图生成后原子更新本任务目录内的 `report.json`。宿主中断后，调用方可读回已完成的角度与采样时间，但 `running` 报告仍属于未完成采样，不能当作完整验收。使用新的唯一前缀补充缺少的视角，完成后清理本次所有目录。

取景范围现在同时覆盖当前骨骼与完整网格包围盒 避免独立武器的枪管超出画面 固定灰色环境贴图仅用于本次相机的环境补光 保留金属结构可辨认性 不启用关卡间接光与动态反射 不修改源材质 世界结束或临时对象已销毁时将采样标记失败 清理本次迭代器 无论清理是否抛错都解除跨帧回调 防止相同错误反复输出
