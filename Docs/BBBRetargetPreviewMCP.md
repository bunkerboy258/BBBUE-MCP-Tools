# 重定向器与运动数据预览

`retarget.configure_fk_retargeter` 作用于明确的现有重定向器，不导出动画。源与目标需要完整的同名身体和手指链。脊柱、颈部采用插值旋转，适配不同骨骼数量；其余链逐骨旋转，不复制源骨长。保留目标重定向姿态，可选择自动对齐源姿态。

存在源 `root` 时，从源根骨复制根运动及高度；引擎会根据角色相对身高缩放根运动。没有源根骨时仍采用工具已有的目标骨盆生成模式，调用者必须核对其适用性。工具移除 Run IK Rig 和旧 Pin Bone 操作，以重定向后的目标手脚生成七个辅助 IK 骨轨道。曲线操作按源名称复制全部曲线，关闭名称重映射。缺少唯一 FK、根骨或曲线操作时拒绝作为完成结果保存。

Motion Matching 的根轨迹、姿势与速度需要从最终目标动画计算。源 `MoveData_Speed` 曲线保留供追溯，不保证与原始骨轨或经过身高缩放后的目标速度一致。源中不存在的接触标记、通知、同步标记及 Pose Search 标签不能通过重定向凭空恢复。导出时另行核对时长、采样率、加法基准、根运动启用与根锁定配置；重定向器预览成功不代表完成全库导出验收。

官方 Slate 工具 `slate_inspector_toolset.Snapshot` 按只读编辑器会话处理；`Click`、`Type` 和 `PressKey` 按编辑器 UI 会话处理，不要求不存在的资产写入路径。必须先以 Snapshot 获取真实控件引用，再执行输入。Type 在现有光标位置输入文本，更换搜索条件时先聚焦文本框，再 PressKey Ctrl+A，随后 Type。资产浏览器中优先对实际名称文本控件双击，等待界面求值后回读，避免把仅选中的行当作正在预览的动画。

2026-10-25 验证：20 项重定向数据、Slate 作用域及相关工具契约测试通过。可视 UE5.8 中实际配置 Manny 与 UEFN 两套源到相同士兵目标，均回读 21 条链、五项操作与七对辅助骨，编辑器初始化成功。完成步行、斜向、急转、蹲行等代表动作预览，保持源库和游戏运行入口不变；未批量导出动画，未进行 PIE。
