# 攀爬动作烘焙

`animation_finish.bake_traversal_action` 接收原始动画、独立 IK 重定向器、目标待机序列及两个新的自有输出路径。动作起止帧包含两端，按原片采样率计算。默认取 30 至 96 帧，进入 0.3 秒、退出 0.4 秒，两端各保留约 0.1 秒站姿。

工具要求停止 PIE。明确输出支持新建或原位重建，已有目标必须类型与骨架一致且没有未保存编辑，源动画和待机不能作为输出。源动作与重定向器源网格骨架一致，待机与目标网格骨架一致，根高度使用 CopyHeightFromSource。通过官方 IK 批量重定向直接创建目标序列，再烘焙首尾站姿与中间完整动作；根位置以裁切起点归零，末端站姿保持登台高度。清理源片遗留曲线、同步标记及通知，回读所有写入轨道后保存。蒙太奇使用 DefaultSlot，全身单次播放，通过原生 ConfigureMontageSections 配置 Enter、Climb、Exit 三段连续，无循环。

返回原始来源、帧范围、采样率、总时长、攀爬区间、根位移和轨道回读误差。此回读只证明保存数据一致，手脚接触和台沿净空仍须用实际目标身体逐帧检查。工具不接入玩法，不使 Mass 自动执行攀爬，不调用版本控制。

当前制作预设使用约 2.5 米攀爬原片，第 40 至 74 帧渐入渐出手掌接触约束，第 48 至 64 帧完整匹配原片双手位置。此区间是本次原片的制作参数，不应直接用于动作时序不同的素材。双骨 IK 禁止伸长手臂，身体偏移有上限且随接触阶段恢复。男女共用原片未缩放的根轨迹，避免体型缩放改变登台高度。返回九个身体骨骼的逐帧位置及首尾站姿误差。
