# 骨骼动画集合导入

入口：`editor.import_skeletal_animation_set`。

- `source_files` 为有序的绝对 FBX 路径数组。第一项必须包含角色网格，可以包含零个或一个动画；后续每项必须为一个动作。
- `destination_path` 必须是没有既有资产的 Game 目录。工具拒绝覆盖。
- `mesh_name` 为源网格资产名称。
- 第一项生成一份网格和骨架。若含动画则保存一次，后续动作均引用该骨架。
- 数字开头的动作文件名在 UE 资产名中加 `AN_`，不改动原始源文件及导入源路径。
- 动画设置源网格作为预览网格。导入结果返回已保存网格、骨架、动作路径与时长。
- 本工具仅导入源骨架，不执行重定向或更改运行时装备配置。
