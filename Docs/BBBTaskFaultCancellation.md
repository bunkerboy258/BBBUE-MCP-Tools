# 已保存故障批次的明确取消

`control_task(action="cancel", batch=...)` 允许原客户端取消失败且处于 fault 的批次.

取消前核对宿主身份 无 PIE 无该批次活动 无其它正在执行的写入 并对故障占用范围执行磁盘与资产回读.目标包存在未保存内容时拒绝取消.无关并行脏包不受影响.

此操作不执行迁移 不保存 删除或还原资产 不将原任务标记完成.保留原失败与恢复记录 将批次标记为 cancelled 及 partial 并在 proof.cancelled_recovery 保存当前回读证据.释放的是已明确取消的故障占用.已经结束但仍处于 releasing 的原干员可以据此完成交接并登记后续任务.

验证命令为 `python -B -m unittest discover -s Tests -p test_mcp_cancel_fault.py`.覆盖已保存故障取消 脏包拒绝及外部客户端归属拒绝.另回归原任务恢复测试.

取消已回读的迁移故障时 同时把待恢复描述移入取消证据并清空不确定写入集合.重启宿主或服务后不再重新生成这个已取消批次的资源占用.原始失败及 partial 结果保留.
