# 同源动画裁帧与曲线时间对应

`editor.copy_animation_float_curves` 保持明确的源序列与目标列表接口。同长序列使用原生完整曲线复制。时长不同的同源序列先核验原始数据模型采样率与根骨及骨盆轨道。

裁帧核验最多接受八帧首尾差异。用骨盆的原始局部变换逐帧确定源起始偏移 最大位置差限制为 0.1 cm 最大旋转差限制为 0.1 度。随后单独检查根轨道 返回 `root_motion_matches` 和根轨道最大误差。根轨道不同的目标只允许预检 必须先通过显式骨轨工具修正并回读后才允许曲线写入。超出骨盆对应限制或原始轨道无效时拒绝操作 不根据文件名推断对应。返回 `alignment` 包含源帧偏移 源秒偏移 最大误差和 `verified_target_end_time`。

通过对应核验后只平移曲线键的时间 保留键值 插值模式 有效切线 颜色 注释和标志。裁帧路径仅接受常量外推。数据模型回读必须保持完整曲线语义 时间文本序列化仅允许一微秒误差。保存前后核对全部骨轨道摘要 禁止因曲线复制改变动作骨骼。

目标的尾部可能比已核验源区间更长。使用者必须将数据库条目的采样上限限制在 `verified_target_end_time` 内 并以源时间减去 `source_time_offset` 换算原有显式采样范围。曲线时间偏移不会自动修改数据库或动作长度。

`dry_run=true` 执行对应核验和键转换预检 不修改目标。应用阶段逐目标保存 不是跨资产事务。部分失败后按已返回的保存证据检查明确目标 不创建备份或兼容资源。
