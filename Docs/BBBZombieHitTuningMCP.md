# 僵尸受击瞬态调参

`hit.configure_pie_hit_tuning` 接收当前 PIE 调参靶、其对应的正式僵尸表现配置、部位编号及线性和角冲量倍率。它将表现配置复制到调参靶内，仅调整所选部位并调用靶子的正式配置入口；结束 PIE 后副本随靶子销毁，不保存或修改源资产。参数非有限、部位无效、靶子不属于当前 PIE、配置不匹配以及轨迹仍在运行时均拒绝操作。

可随后调用靶子的 `StartHitTrajectory`，结合同相位参考骨架和原有分析器测量部位的角度、速度、回正、关节及骨段误差。调参靶不是正式 Mass 实体，数值通过不代表子弹链路、尸群性能或主观效果通过。

`hit.start_skeletal_hit_reaction_capture` 对需要命中的采样要求收到相应的受击编号；临时表现演员尚未应用正式配置而没有消费命中时，采样明确失败，不再把零反应输出为完成。

轨迹请求的 `variant` 和 `animation` 必须与调参靶当前资产一致 原生入口会校验并记录实际资产以及逐帧动画时钟 运动肢体除了角度还记录实际骨骼位移 用同一套最大角度 速度 关节误差与恢复门槛检查安全边界 行进肢体可以通过对应部位角度门槛或八厘米的位移达到冲击幅度门槛 静止测试保持原角度门槛

轨迹采样可显式设置 `command: true` 使用调参靶的 `PreviewHit` 标准点命中指令 固定指定部位不会被移动的其它身体部位遮挡 不设置时使用真实 Pawn 通道射线 两种入口分别记录实际骨骼和部位 基线对照要求入口相同 此开关仅属于调试靶 不改变正式子弹碰撞
