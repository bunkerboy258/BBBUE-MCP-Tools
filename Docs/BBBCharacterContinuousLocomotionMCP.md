# 角色连续移动循环

`animation_graph.configure_character_continuous_locomotion` 仅在共享资产编辑宿主非 PIE 状态下调用。先完成源码编译并重启宿主，再查询工具参数。

参数指定角色主动画蓝图、基础装备动画层、装备后代层数组、角色移动配置、新输出目录及急转最低实际速度。装备层按父层在前排列，包含所有中间层，不重设现有继承关系。工具只读提取装备层的既有四向循环与待机；三种步态的样本位置取配置中的前进、侧移、后退速度。每个装备层生成三份五样本二维 BlendSpace。

构图只替换基础层 `FullBody_CycleState` 的循环播放器和 `UpdateCycleAnim` 内的方向离散换片；仍由同一线程安全更新函数处理步态资产切换与步幅权重。主 `AnimGraph` 的节点、连线和布局保持不变。最低速度加入既有 Pivot 入场条件，不修改角色输入、CMC 或网络事实。

要求目标资产写入预检通过且没有未保存编辑。装备层必须属于基础层的完整指定继承树，动画和混合资产必须同骨架；拒绝重复构图、覆盖既有输出目录、缺失样本和非有限速度。全部相关蓝图无警告编译通过后保存。图表导出、实际 Enhanced Input 游戏帧序列和角色动画探针用于验收，不能把工具返回成功当作视觉验收通过。

`animation.start_pie_character_motion_capture` 在可渲染的运行中 PIE 上启动非阻塞观察；按实际游戏更新间隔记录正式动画图骨骼及跟随角色的截图。不暂停游戏、不更改时间缩放、不把动画切换为单节点模式。随后在同一宿主执行 Enhanced Input 序列，通过 `animation.get_pie_character_motion_capture_status` 查询完成状态与报告路径。输出仅位于该测试宿主的 `Saved/temp/<file_prefix>/`，前缀目录必须新建。
