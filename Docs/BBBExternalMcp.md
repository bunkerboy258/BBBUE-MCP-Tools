# 第三方动作

来源与许可证见 [项目依赖](ProjectDependencies.md)。

对官方工具和项目工具的现有能力缺口保留白名单动作。公开工具 ID 为 `external.<领域>.<动作>`。

## 调用

1. `find_tools` 搜索目标，例如 `external.animation list_notifies`。
2. `describe_tool` 获取该动作的明确参数。
3. `submit_batch` 传入普通参数对象。
4. 查询批次并核验业务结果。

网关负责内部动作分发。参数结构从实际函数声明生成，输入先核验。每个动作独立检查自身原生依赖。

## 范围

保留动画、Control Rig、数据表、编辑器、输入配置、层、关卡、序列、重定向、诊断和截图动作。官方入口与项目入口承担已经覆盖的操作。

动作的范围、权限和世界约束以当前单项契约为准。资产操作通过源控检查，场景修改使用完整基线与实际回读。
