# 动画库批量导入

`editor.import_animation_library_batch` 每批一至十六个明确新目标，复用给定骨架和预览网格，支持单独的导入旋转，拒绝覆盖。每个动作单独保存。操作期间使用原生 FBX 工厂并恢复原 Interchange 开关，源文件路径直接指向永久原文件，不复制到自动导入目录。

`editor.clone_retargeter_for_source_mesh` 复制审核过的源 Rig 和重定向器，更换新源网格，保留目标姿势和操作栈，仅重新对齐新源。目标 Rig 与模板不修改。

`editor.audit_animation_library_batch` 只读核验逐对源目标时长、浮点曲线名称与键值、通知数量，以及目标全帧七个辅助 IK 骨的变换和轨道。检查位置误差不超过 0.02 cm、旋转不超过 0.05 度。不替代视觉验收。

导入旋转必须使用明确的 pitch、yaw、roll 命名参数，按源骨架实际参考朝向校准；不能仅凭 FBX 的 UpAxis 对所有骨架使用同一旋转。已存在的审核资产在批次外复用，不重复导入。

`retarget.retarget_sequences` 通过公共资产写入规则校验并保存，不强制将未受控资产打开添加；仍保留受控资产的他人占用与冲突保护。

验收：三项独立导入测试通过；实际库 340 条动画、10,184 帧通过全帧检查，最大辅助 IK 位置误差 0.001731 cm、旋转误差 0.001680 度。
